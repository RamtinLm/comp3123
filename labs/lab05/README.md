# Lab 05 - Express Routing and Middleware

Express server with routers (/books, /books/computers), a logging
middleware (server_log.txt) and the class exercise routes.

## Setup
npm install
npm start

Server runs at http://localhost:8081

## Routes
GET/POST/PUT  /books
GET/POST/PUT  /books/computers/game-dev
GET           /books/computers/java
GET           /books/computers/python
GET           /home
GET           /profile
POST          /login
GET           /logout/:username
GET           /error
